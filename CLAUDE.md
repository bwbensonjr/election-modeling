# Development Guidelines 

- Use Python, `uv`, and `pyproject.toml` for development and scripting.
- Use the `bwbensonjr` repositories and tools for data collection and transformation.
- The data collection process should be reproducible and expandable, but we will save the processed data used for modelling.
- Use OpenSpec change design and change proposal for building the system. Do not use the `brainstorming` skill.
